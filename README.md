# Ритм

Веб-тренажёр десятипальцевой печати на русском и английском языках. Работает без сервера приложения, учётной записи и сборки: HTML, CSS и JavaScript modules. Данные сохраняются в localStorage текущего браузера.

## Возможности

- 16 уроков для ЙЦУКЕН и 16 для QWERTY: основной ряд, верхний, нижний, цифры, Shift и связный текст.
- Короткая лекция перед каждым уроком и подробная инструкция с постановкой пальцев.
- Схема рук, зоны пальцев, подсказка следующей клавиши и противоположного Shift.
- Переключатель «Показать руки»: полупрозрачные руки прямо над клавиатурой, движение нужного пальца к букве, подсветка большого пальца для пробела и противоположного мизинца для Shift. Настройка сохраняется в браузере.
- Практика на своём тексте, образце и трудных клавишах последних 10 занятий.
- Ошибка останавливает курсор; Backspace исправляет её, сохраняя ошибку в статистике.
- Таймер запускается с первой попытки, исключает паузы и время отсутствия фокуса.
- Точность — доля правильных попыток; скорость — набранные символы в минуту активного времени. WPM не используется.
- Урок считается пройденным при точности от 95%; все уроки доступны для самостоятельного выбора.
- Локальный профиль с именем; настройки, язык и выбранные уроки сохраняются автоматически.
- История до 500 занятий и график скорости; прохождение уроков хранится отдельно и не теряется при сокращении истории.
- Полный перенос профиля через JSON-файл: экспорт, проверка и предварительный просмотр импорта, применение в новом браузере. Чтение файла и сохранение выполняются целиком на клиенте. Поддерживаются старые файлы `ritm-progress.json`. Импорт заменяет текущие локальные данные только после проверки и нажатия «Применить файл».
- Добавление раскладок с рядами 13/12/11/10 символов и отдельным отображением Shift. Автоматически создаются восемь стартовых уроков.

Выбор языка приложения не переключает раскладку операционной системы. Тренажёр принимает фактически введённые символы. Для практики десятью пальцами нужна физическая клавиатура.

## Запуск

```sh
python -m http.server 4173 --directory dist
```

Открыть http://localhost:4173. Подойдут любой статический хостинг или Sites. В `.openai/hosting.json` каталог публикации — `dist`.

## Проверка

```sh
npm test
```

Проверяется покрытие символов всех 32 уроков, последовательность ввода изученных клавиш, зоны пальцев, ошибки и их исправления, формулы точности/скорости, завершение и исключение пауз из таймера.

Браузерная проверка проведена в Chromium: первый урок, ошибка, Backspace, пауза и продолжение, завершение, следующий урок, сохранение после перезагрузки, переключение языка, валидация текста, Shift, добавление немецкой раскладки и экран 390px.

## Структура

`dist/course.js` — раскладки, учебная программа и модель тренировки. `dist/app.js` — интерфейс; `dist/storage.js` — формат резервной копии, миграция и проверка данных. `dist/styles.css` — адаптивный дизайн. Новые встроенные языки добавляются в `builtinLanguages`, индивидуальные — через форму в приложении.

## Методика

Используются традиционные принципы обучения: закреплённые зоны пальцев, исходная позиция, последовательное введение клавиш, сочетания и слова, повторение трудных клавиш, обратная связь и короткие регулярные занятия. Лекции и упражнения написаны специально для приложения. Порог 95% — настройка курса, а не научно установленный универсальный стандарт. Методика не обещает определённую скорость или срок обучения.

Источники рекомендаций по технике: [Ratatype](https://www.ratatype.com/learn/) и [TypingClub](https://www.typingclub.com/).
